Publicação no GitHub

Com o token configurado, os artigos e membros da equipe criados no admin são salvos diretamente no repositório e ficam visíveis para todos imediatamente.

Crie um token em github.com → Settings → Developer settings → Personal access tokens com permissão de escrita no repositório falaw. O token também habilita o uso dos GitHub Models (gpt-4o-mini gratuito) como IA de fallback.

Autenticação — Supabase

Use o Supabase para autenticação/acessos (admin e clientes), newsletter, contatos, currículos, relatórios e todos os dados dos dashboards. Requer executar o script SQL em supabase-setup.sql no SQL Editor do Supabase.

Crie um projeto em supabase.com, vá em Settings → API e copie a Project URL e a anon public key. Com GitHub Token configurado, as páginas públicas são atualizadas automaticamente.
